# Education Hub — Roles & Duties

This document specifies the duties and system permissions of every role in the institute.
A PDF version is published in-app under **Documents → "Roles & Responsibilities"** (visible to teachers, volunteers, and administrative staff).

---

## 1. Admin (Principal / Institute Administrator)

**Duties**
- Overall administration of the institute in the system
- Create and manage all accounts: teachers, volunteers, administrative staff, parents, student logins
- Configure the institute: custom grade levels, classes, subjects, report card format and logo
- Assign teachers (including co-teachers) to classes and duties to administrative staff
- Review and approve/reject marks submitted by teachers before report cards are generated
- Publish school documents (schedules, events, notices, circulars) and manage the holiday calendar

**System permissions**
| Area | Access |
|------|--------|
| All modules | Full create / edit / delete |
| Marks approval | Approve, reject with reason, bulk approve |
| Report card customization | Institute name, tagline, logo, grading scale, visible sections |
| Documents & calendar | Upload/delete documents, add/delete holidays, choose per-document audience |

---

## 2. Teacher (Class Teacher)

A teacher assigned to a class by the admin. **Teachers only see the classes assigned to them.**

**Duties**
- Maintain daily student attendance for their classes
- Create exams (mid-term written/oral, final written/oral, class tests, projects) and enter marks
- Submit entered marks to the admin for approval; correct and resubmit if rejected
- Assign homework (optionally referencing a book from the class book list)
- Generate and review report cards for their students after marks are approved
- Manage class books and refer to school documents/calendar

**System permissions**
| Area | Access |
|------|--------|
| Own classes, students, exams, homework | Full manage |
| Other classes | No access (hidden and blocked) |
| Marks | Enter/edit while draft or rejected; read-only once submitted/approved |
| Report cards | View/print/PDF for own students |
| Documents & calendar | View only |
| Volunteer attendance | Record it (Volunteers tab on Attendance page) |

---

## 3. Co-Teacher

A class can have **multiple teachers assigned — even for the same subject**. Every assigned teacher is a full co-teacher of that class.

**Duties**
- Share all class-teacher duties above for the shared class: attendance, marks entry, homework, report cards
- Coordinate with fellow co-teachers so duties are split (e.g., one enters marks, one maintains attendance)

**System permissions**
- Identical to a class teacher, for every class they are assigned to. There is no difference in access between the "first" teacher and any co-teacher.

---

## 4. Administrative Staff

Non-teaching staff whose duties are **customizable per person** by the admin.

**Duty types** (assigned from Admin → Admin Staff → Assign Duty)
| Type | Typical responsibilities |
|------|--------------------------|
| Class Support | Assist the class teacher of a specific class — materials, supervision, escorting students |
| Laboratory | Lab equipment setup, maintenance, safety, inventory |
| Office Work | Front desk, admissions paperwork, records, correspondence |
| Custom (any label) | e.g. Library, Transport/bus duty, Canteen, Security, Examination cell |

Each duty can carry a details note (e.g. "Morning shift", "Science lab only").

**System permissions**
| Area | Access |
|------|--------|
| My Duties dashboard | View own assignments (read-only) |
| School calendar | View only |
| School documents | View those shared with the Staff audience |
| Academic data (marks, students, attendance) | No access |

---

## 5. Volunteer

Community members who help with day-to-day supervision.

**Duties**
- Mark daily student attendance for any class
- Support teachers during events and activities
- Attend staff/volunteer meetings (see Documents → notices)

**System permissions**
| Area | Access |
|------|--------|
| Student attendance | Record for any class |
| Own attendance | View only (recorded by admin/teachers; corrections via admin) |
| Marksheets / report cards | View/print only |
| Homework | View only |
| Documents & calendar | View only |
| Any editing of marks, homework, configuration | Blocked |

---

## 6. Student

**Duties**
- Complete assigned homework by the due date (referenced book shown on each assignment)
- Use book copies (PDF/scans) shared by the school
- Keep track of schedules, events, and holidays via Documents and Calendar

**System permissions**: view own profile, homework, book list, attendance, shared documents, and calendar. No editing.

## 7. Parent

**Duties**
- Monitor children's attendance, homework, and book requirements
- Stay informed via shared documents and the holiday calendar

**System permissions**: view linked children's details, attendance, homework, and books; view calendar. No editing. Parents may self-register using their child's roll number.
